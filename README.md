# Field2Sim project page

Source of the Field2Sim (WACV 2027) project website, served by GitHub Pages from the `gh-pages` branch.

The site is built on the [Nerfies website template](https://github.com/nerfies/nerfies.github.io).

## Editing

- Page content lives in `index.html`; search for `TODO` to find the placeholders.
- Put videos in `static/videos/` and images in `static/images/`, then uncomment the matching teaser / carousel / video sections in `index.html`.
- Preview locally with `python3 -m http.server` and open http://localhost:8000.
